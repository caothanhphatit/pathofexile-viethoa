POEVH / Cấu hình

Quản lý instance

Mỗi instance có cấu hình, process và tài khoản riêng.

Quản lý instance

Mỗi ID là một profile riêng; nhiều profile có thể cùng là Standalone. Bạn có thể chọn Steam làm main. Steam/Epic mở thủ công qua launcher. Reset mô phỏng không xóa profile đã lưu.

Gắn PID xác nhận process ở mức Windows, không xác nhận đọc dữ liệu nhân vật. Main ở đây là profile chính; chưa chuyển nguồn memory reader/tay cầm theo PID. Tự đăng nhập đang thử nghiệm cho Standalone. Ghép tay cầm theo process và áp đồ họa riêng chưa được hỗ trợ.

Chỉ mở đường dẫn EXE đã lưu cho từng profile; không tự chọn một bản cài đặt khác.
